# I-CARE dataset access

The raw I-CARE EEG database is not bundled in this archive.

- Dataset page: https://physionet.org/content/i-care/2.1/
- Registry description: https://registry.opendata.aws/bdsp-icare/
- Approximate size: 2.63 TB for the full PhysioNet release.
- Scope: harmonized clinical information and continuous EEG from more than 1,000 patients who were comatose after cardiac arrest, collected across seven hospitals.
- Format: WFDB-compatible records, with EEG signals stored in MATLAB v4 files and accompanying headers/metadata.

Check the current PhysioNet access terms, citation instructions, and storage/compute requirements before downloading. Start with metadata and a small permitted subset rather than attempting the complete multi-terabyte download on a desktop computer.

The bundled `I_CARE_2023_EEG_Database_Paper.pdf` is the peer-reviewed database description associated with DOI 10.1097/CCM.0000000000006074.
