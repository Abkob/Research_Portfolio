# Curation and source boundary

This public portfolio was assembled from local project repositories, reports, research plans, evidence maps, and source indexes. It is not a bulk upload of the laptop.

## Included

- Original project summaries and stage labels
- Links to public code repositories
- Research questions, architecture conclusions, and validation plans
- Primary-source DOI or project links where useful
- Aggregate technical facts already documented in project materials
- An anonymized NeuroSense dashboard reconstruction and an original public case-study synthesis
- Public-safe MotorBrace notebooks plus team-attributed proposal/mechanical reports
- Public-safe AARS segmentation notebooks plus selected design reports with an explicit claims disclaimer
- Provenance-bounded summaries of the brain-tumor and fire-detection studies

## Not uploaded

- Raw ECG, EEG, ECoG, imaging, or other human-subject recordings
- Student workbooks, identifiers, databases, exports, logs, or embeddings
- Business databases and backup archives from private systems
- Downloaded journal PDFs or extracted publisher figures
- API keys, environment files, connection strings, or deployment secrets
- Whole team reports or unpublished collaborator material
- Drive folders containing only trained models, empty directories, or redundant subsets
- An upstream YOLOv3 tutorial notebook that was not original project code
- Brain-tumor derivative notebooks whose redistribution rights and original-cell boundaries were not clear
- NeuroSense participant metadata, raw sensor data, internal meeting transcript, and illustrative metrics presented as clinical results
- Generated build directories, package caches, model weights, and redundant archives

## Why

A professional research portfolio should make work inspectable without violating data-use agreements, copyright, privacy, security, or collaborator ownership. Source papers are cited or linked at their publisher/project pages; private data stays private; case studies state whether they are plans, implementations, or validated results.

## Duplicate decisions

- The small `MotorBrace(Ab)` folder was a subset of the fuller MotorBrace archive and was merged conceptually into one project.
- `Project_62625` and its large unnamed model folder were one Attention U-Net experiment; the weight file was excluded. The later WeedBot adaptation is represented inside AARS.
- Duplicate/near-duplicate BCI Week 1 notebooks were not added again; the existing curated versions remain canonical.
