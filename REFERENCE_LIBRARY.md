# Extracurricular Reference Library

This is a catalog of books, course notes, and reference material from a personal self-study folder. It is **not** a list of authored publications, a claim that every item was completed cover to cover, or a redistribution archive.

The source folder contained 55 document files plus one cover image. Duplicate copies and edition variants are consolidated below. No commercial PDF or EPUB is hosted in this repository; readers should use the publisher, author, library, or lawful open-access edition.
